# Reto 1 Equipo 3

Este código solicita los datos de un jugador y de un equipo a través de un menú de opciones.

---

## Tecnologías utilizadas

Este proyecto fue construido utilizando las siguientes tecnologías:
* **Lenguaje:** Java
* **Base de datos:** MER y relacional.
* **Entornos de desarrollo:** Diagrama de casos de uso y documentación.
